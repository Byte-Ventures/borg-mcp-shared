This recovery release includes the protocol v9 conformance correction intended
for 0.12.1 and prevents known high-severity dependency advisories from reaching
future release tags.

- Retry conformance now compares resolved delivery rather than ignored request fields.
- Genuine resolved class-routing changes still return `POST_ID_CONFLICT`.
- The development lock uses the fixed nanoid release, and ordinary CI now runs the same high-severity audit required by the tag workflow.
