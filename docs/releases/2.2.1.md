This patch updates built-in role templates to use canonical underscore tool
names, including `borg_ack_status`, `borg_update_cube`, `borg_put_document` and
`borg_get_document`. These references work as JavaScript property names in
OpenCode 2 Code Mode.

Adopt these templates with a client that supports the underscore tool catalog.
Existing saved roles are not rewritten. Public exports and protocol 14 remain
unchanged.

Development test dependencies are updated to resolve the dependency-audit
findings that blocked the release checks. The package has no runtime dependencies.
