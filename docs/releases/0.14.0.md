This release introduces the protocol v11 acknowledgement-status contract used
by the matching Borg MCP server and client releases.

- A read-only entry-specific query reports the entry visibility and each intended recipient's nullable acknowledgement timestamp.
- Advisory claims remain separate from acknowledgements, with nullable current drone labels and roles in both collections.
- Unknown entries return a typed refusal instead of being represented as missing acknowledgement state.
- Conformance vectors prove that status queries do not acknowledge, claim, or consume unread activity.
- Shipped Coordinator guidance uses `borg_ack-status` to inspect receipt without advancing unread cursors.
