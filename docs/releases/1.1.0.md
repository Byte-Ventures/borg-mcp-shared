This release advances the shared contract to protocol tag 13 and removes legacy
surface area before the next coordinated client and server releases.

## Compatibility

- The protocol tag changes from 12 to 13. Tag 13 requires a matching consumer pair; mixed tag 12 and tag 13 consumers fail closed.
- The client must stop sending the removed `default` template before adopting this package. `borgmcp-server` 3.3.0 and `borgmcp` 4.7.0 are the adopting releases.

## Breaking API changes

- The deprecated `ErrorResponse` export is removed.
- Eight unused `ErrorCode` members are removed: `SUBSCRIPTION_REQUIRED`, `MISSING_PARAMETER`, `RATE_LIMIT_EXCEEDED`, `DATABASE_ERROR`, `EXTERNAL_SERVICE_ERROR`, `ROLE_HAS_FROZEN_DRONES`, `DRONE_FROZEN`, and `CURSOR_INVALID`. `SESSION_REJECTED` and `INTERNAL_ERROR` remain available.
- `LEGACY_DEFAULT_TEMPLATE_LABEL` and the legacy `default` cube-template branch are removed.

## Reliability and verification

- `getTemplate` now rejects inherited object keys instead of treating them as registered templates.
- The portable adapter conformance suite now observes behavior without implementation-specific state inspection (`#149`, `#150`). Prerequisite failures are isolated, hostile-mutation controls prove refusal atomicity, and human-seat occupancy remains in force until eviction.
- Release CI is smaller and uses the repository's current release-identity and packed-artifact checks (`#152`, `#154`). CI tests both the supported minimum Node.js 22.12.0 runtime and the Node.js 24.19.0 release runtime (`#156`).
