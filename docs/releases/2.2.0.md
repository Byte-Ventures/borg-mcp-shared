This minor release adds design-reference guidance to the Software Development,
Starter, and Local Model templates.

Each issue keeps its mockups and design documents in one GitHub gist, linked
from the issue as `Design reference: <gist url>` and revised in place. When a
design reference exists it is the acceptance visual: the scope contract names
the gist revision, builders verify against it before handing over and state
any deviation, reviewers treat an unstated mismatch as blocking, and release
quality verifies the final result against the current revision before close.
